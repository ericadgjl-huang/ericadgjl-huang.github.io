# EPPS 6356 Personal Website

This repository contains my personal academic website for EPPS 6356 Data Visualization at the University of Texas at Dallas.

The website is built using Quarto and RStudio and hosted with GitHub Pages.

## Rebuild the Website

1.  Clone or download this repository.

2.  Open `epps6356-website-eric.Rproj` in RStudio.

3.  Edit the `.qmd` files as needed.

4.  Render the website using:

    quarto render

5.  The rendered HTML files will be generated in the `docs/` folder.

6.  Commit and push the updated files to GitHub.

7.  GitHub Pages publishes the site from the `main` branch and `/docs` folder.
