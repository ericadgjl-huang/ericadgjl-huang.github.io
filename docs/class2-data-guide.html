Class 2: Huang’s Data Guide

A personal data-inspection checklist adapted from the Quartz Bad Data Guide.

A personal checklist for inspecting a dataset before I analyze or visualize it. Adapted from the Quartz Bad Data Guide (Christopher Groskopf and contributors, CC BY-NC 4.0) and organized by who can fix the problem, with extra items for the two kinds of data I work with: gridded weather reanalysis and medical imaging datasets.

Prepared for EPPS 6356 Data Visualization (Prepare for Class 2), Fall 2026.

How I use this

I do not walk through all 60 items every time. I run Tier 1 on every new dataset (15 minutes), then go to the section that matches whatever looks wrong.
