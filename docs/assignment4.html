Chart 4: Column Chart of Continental Means

Implementation (Comparison: One Variable across a Few Items)

Chart 4 completes the Abela comparison branch at its coarsest grain: one variable (the Happy Planet Index) across a few items (the five continents). Continents are ordered by mean HPI with forcats::fct_reorder() rather than alphabetically, so the ranking is read from position along a common baseline (Cleveland & McGill 1984) instead of recovered by scanning labels. The mean here is unweighted, which distinguishes it from the population-weighted mean in Chart 1; the two figures are not interchangeable and the subtitle says so. Because a continental mean conceals how many countries it averages — four for Oceania against seventeen for Asia — the count is printed inside each column rather than relegated to a footnote.

The code

The chart runs against hpi_clean, the cleaned 2024 subset shared by the whole team, and the palette and theme_hackathon() come from R/theme.R so that all four charts share one visual language.

df_chart4 <- hpi_clean %>%
  group_by(continent) %>%
  summarise(
    mean_hpi = mean(hpi, na.rm = TRUE),
    n        = dplyr::n(),
    .groups  = "drop"
  ) %>%
  mutate(continent_ordered = fct_reorder(continent, mean_hpi, .desc = TRUE))

p4 <- ggplot(df_chart4, aes(x = continent_ordered, y = mean_hpi, fill = continent)) +
  geom_col(
    width = 0.68,
    show.legend = FALSE
  ) +
  geom_text(
    aes(label = sprintf("%.1f", mean_hpi)),
    vjust = -0.55,
    size = 3.6,
    fontface = "bold",
    color = "#222222"
  ) +
  geom_text(
    aes(y = 1.8, label = paste0("n = ", n)),
    size = 2.9,
    color = "#FFFFFF",
    fontface = "bold"
  ) +
  scale_fill_continent() +
  scale_x_discrete(name = "Continent") +
  scale_y_continuous(
    name   = "Mean Happy Planet Index Score (0-100 Scale)",
    limits = c(0, 62),
    breaks = seq(0, 60, by = 10),
    expand = expansion(mult = c(0, 0.02))
  ) +
  labs(
    title    = "The Americas Convert Resources into Wellbeing More Efficiently Than Any Other Continent",
    subtitle = "Unweighted mean Happy Planet Index of the countries in each continent; n gives the number of countries behind each column.",
    caption  = "Source: Happy Planet Index (2024 Edition) | EPPS 6356 Hackathon"
  ) +
  theme_hackathon(legend_pos = "none") +
  theme(
    # theme_hackathon() re-declares axis.title.y through %+replace% without an
    # angle, which prints the title flat and squeezes the panel; the same fix
    # is applied in Chart 1.
    axis.title.y = element_text(angle = 90, vjust = 2, margin = margin(r = 10))
  )

Analytical Takeaway

  • The Americas lead on efficiency, not on income. At a mean of 53.5 across sixteen countries, the Americas sit roughly four points above Oceania (49.7) and nearly six above Europe (47.9), despite a lower average GDP per capita than Europe. This is the HPI’s central claim made visible at continental scale: the index rewards converting resources into long, satisfying lives, not accumulating resources.
  • Africa’s position is a footprint artefact as much as a wellbeing one. Africa’s mean of 36.3 is the lowest of the five, but the cohort spreads from 21.1 to 47.6 — a range wider than the gap between the top two continents. Reading the column as a statement about “Africa” rather than about its mean would be exactly the error the embedded counts are there to resist.
  • Oceania’s column is the least reliable and says so. Four countries stand behind a mean of 49.7, against seventeen behind Asia’s 43.3. Printing n inside the bar keeps that asymmetry in the reader’s eye at the moment of comparison; without it, five columns of identical construction imply five estimates of identical precision.
  • Sorting is the analysis. Ordering by mean rather than alphabetically turns the ranking into a single left-to-right read. Wickham (2010) names alphabetical ordering of categorical variables as a common and avoidable fault, after Wainer’s “Alabama first!”; here, sorting is what allows the title’s claim to be verified by looking.

What I had to fix

  • The y-axis title came out horizontal. theme_hackathon() re-declares axis.title.y through %+replace% without an angle, so the angle resets to zero, the title prints flat at the far left, and the panel is squeezed. I caught it by comparing my first render against Chart 1, where the same fix (element_text(angle = 90, vjust = 2, margin = margin(r = 10))) already appears. Commit 07f074f.
  • The first draft of the commit would have touched the whole repository. The clone is on Windows, so every text file in the repo showed as modified on line endings alone — 13,521 insertions and 13,527 deletions across 52 files, all whitespace. I staged only the paths I had actually added instead of using git add -A, so the history stays readable.
  • source("R/theme.R") pointed at a file that was not in the repository. Chart1.R and Chart3.R both call it, but the theme existed only inside the setup chunk of the Quarto document, so those two scripts failed from a clean R session.
