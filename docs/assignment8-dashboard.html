About this dashboard

The Happy Planet Index (HPI) combines life expectancy and life satisfaction with each country’s ecological footprint: a high score means long, happy lives at a low environmental cost.

Reading the numbers: HPI scores run from 0 to 100. In 2025, 134 countries have a score. The average change compares the 74 countries that have a score in both 2006 and 2025.

Why is Taiwan missing? Taiwan is in the source file with life expectancy and life satisfaction, but it has no ecological footprint data, so it has no HPI score.

How to use it: hover over any line, point or bar to see the exact values. The Data page has the full table for every country and year, with search, sorting and filters.

A prototype for our team project. Our final project studies discipline disparities in Texas school districts with TEA data, which our team is still preparing. This HPI version tests the layout I plan to reuse: headline value boxes, a trend over time by group, a comparison chart and a searchable table. See the project plan.

Built in R with Quarto dashboards, ggplot2, plotly and DT.
